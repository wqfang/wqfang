## Wenqiang Fang

Simulation and mechanics engineer in the Boston area. PhD in solid mechanics
from Brown University; now a research engineer building simulation and software
tools in industry.

I work on making simulations trustworthy: verifying finite element analysis
(FEA) results against theory, understanding where contact models break down, and
applying that to physics simulation for robot learning.


### Selected work

- **[fea-portfolio](https://github.com/wqfang/fea-portfolio)**: FEA verification
  suite. Cantilever, plate-with-a-hole and Hertz contact benchmarks solved in
  CalculiX and cross-checked in Abaqus, with every discrepancy traced to its
  cause.
- **[FEA-Hyperelastic](https://github.com/wqfang/FEA-Hyperelastic)**: finite
  element implementation of a neo-Hookean hyperelastic constitutive law.
- **[FEA-PhaseFieldMethod](https://github.com/wqfang/FEA-PhaseFieldMethod)**:
  finite element implementation of quasi-static phase-field brittle fracture.
- **[HCMP_Project](https://github.com/wqfang/HCMP_Project)**: 3D cell traction
  estimation from image data.

### Currently

- Learning robot simulation and control: classical control and reinforcement

- Interested in contact and deformable-body modeling in robotics simulators.
